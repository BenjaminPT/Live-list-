# Ritual — трекер привычек (PWA)

Офлайн-приложение: привычки с тепловыми картами, дневник настроения, аналитика.
Чистые HTML/CSS/JS без сборки и зависимостей. Данные хранятся только на устройстве
(привычки и записи — localStorage, фото и голос — IndexedDB).

## Возможности
- Привычки: отметка, счётчик, воздержание; расписание «каждый день / N раз в неделю / по дням недели»
- Серии с уважительными пропусками и режимом «Тяжёлый день»
- Цели с дедлайном («N дней к дате»)
- Дневник: настроение 1–10, теги, поиск, фото и голосовые заметки, авто-отметка привычки из дневника
- Анализ: график настроения, влияние привычек на настроение, причины пропусков
- Недельный обзор с «фокусом на неделю» и 17 достижений
- Тёмная / светлая / авто тема, русский и English
- Экспорт и импорт (включая фото и голос), напоминание: уведомление и файл .ics для календаря

## Запуск локально
    python3 -m http.server 8080      # открыть http://localhost:8080

## Публикация
Push в `main` запускает GitHub Actions (`.github/workflows/pages.yml`) и публикует сайт на GitHub Pages.

## Структура
- index.html, manifest.json, sw.js — оболочка PWA и офлайн-кэш
- css/style.css — токены тем и компоненты
- js/i18n.js, js/lang-en.js — локализация (ключ = русский текст)
- js/store.js — данные, серии, цели, достижения, обзор, медиа
- js/anim.js — пружинные анимации (Web Animations API + CSS linear())
- js/charts.js, js/ui.js, js/icons.js — графики, экраны, иконки

При изменении файлов поднимите VERSION в sw.js, чтобы клиенты обновили кэш.
Новый язык: добавьте словарь по образцу lang-en.js и пункт в настройках.

## 2.1

- **Шаблоны привычек** — при первом запуске экран с 15 готовыми привычками (выбор нескольких за раз), а также из пустого экрана и из формы новой привычки. Демо-данные теперь по желанию.
- **Ваш год в привычках** — анимированные истории: ритм года и тепловая карта, любимая привычка, лучшая серия, лучший день недели, настроение, награды; картинка 1080×1350 для сохранения/отправки. Доступно в «Анализе», а в декабре и первой половине января — баннером на главном экране.
